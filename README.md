# 🎭 AI-Orchestra

多AI协作智能引擎 - 让10个AI一起为你工作

## 🚀 快速开始 (Mac)

### 1. 安装依赖
```bash
cd ~/Desktop/AI-Orchestra
pip install -r requirements.txt
```

### 2. 启动Web界面
```bash
streamlit run ui/app.py
```

浏览器会自动打开 `http://localhost:8501`

---

## 🎯 三种工作模式

### 1. 三级决策模式
**6学生 → 3老师 → 1校长**

适合复杂问题的多维度分析：
- 学生组：6个AI同时回答，覆盖不同角度
- 老师组：3个AI评判打分，指出优劣
- 校长：1个AI综合决策，给出最终结论

### 2. 文学创作模式
**大纲 → 扩写 → 润色 → 审核**

支持多种创作类型：
- 📝 网络小说：世界观、人物、爽点设计
- 📕 小红书文案：标题、种草、标签
- 📰 公众号文章：深度长文，有观点
- 🛍️ 电商文案：转化导向，痛点+卖点

### 3. AI大乱斗 (狼人杀)
**10个性格各异的AI进行狼人杀**

完整游戏流程：
- 🌙 夜晚阶段：狼人刀人、预言家验人、女巫救人
- ☀️ 白天阶段：讨论发言、投票处决
- 🏆 胜负判定：好人 vs 狼人
- 📜 完整游戏日志记录

角色配置（10人局）：
- 🐺 狼人 x 2
- 🔮 预言家 x 1
- 🧙 女巫 x 1
- 🔫 猎人 x 1
- 👤 平民 x 5

## 🎭 AI性格系统

每位AI随机获得一种性格，影响回复风格：

| 性格 | 特点 |
|-----|-----|
| 🔴 激进型 | 喜欢反驳，逻辑硬核，简短有力 |
| 🔵 谨慎型 | 说话滴水不漏，留有余地 |
| 🟡 幽默型 | 爱说烂梗，轻松幽默 |
| 🟢 学霸型 | 列提纲引用数据，结构化 |
| 🟣 和事佬 | 倾向平衡，求同存异 |

## ⚙️ 配置真实API

编辑 `config.yaml`，填入API Key：

```yaml
api_keys:
  deepseek:
    api_key: "your-api-key"
    base_url: "https://api.deepseek.com/v1"
    model: "deepseek-chat"
```

支持的AI：
- DeepSeek
- 豆包 (火山引擎)
- 通义千问
- 腾讯元宝/混元
- Moonshot Kimi
- OpenAI GPT-4
- Anthropic Claude

## 📝 使用示例

### 三级决策模式
1. 输入问题："量子纠缠是否支持超光速通信？"
2. 点击"启动协作分析"
3. 查看6个学生的不同角度回答
4. 查看3位老师的专业评判
5. 获得校长的最终决策
6. 导出完整报告

### 文学创作模式
1. 选择"网络小说"
2. 输入主题："重生之我在末世开超市"
3. 添加要求："爽文风格，主角有空间异能"
4. 查看AI协作创作过程（大纲→情节→润色）
5. 导出最终作品

### 狼人杀模式
1. 选择游戏人数（6-12人）
2. 点击"开始新游戏"
3. 查看随机角色分配
4. 点击"进行下一轮"推进游戏
5. 观察夜晚行动和白天讨论
6. 查看游戏日志和胜负结果
7. 导出完整游戏记录
